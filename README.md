# افزونه مخفی کردن درگاه اسنپ‌پی در ووکامرس

**SnappPay Conditional Gateway Hide** یک افزونه سبک برای ووکامرس است که به مدیر فروشگاه اجازه می‌دهد درگاه پرداخت اسنپ‌پی را برای بعضی کالاها نمایش ندهد.

با این افزونه می‌توانید مشخص کنید اگر محصول داخل سبد خرید مربوط به یک دسته‌بندی خاص، برند خاص، یا چند محصول مشخص بود، درگاه اسنپ‌پی در صفحه پرداخت ووکامرس مخفی شود.

توسعه‌دهنده: [Developer Nima Shadman](https://nimashadman.ir)

## کاربرد افزونه

این افزونه برای فروشگاه‌هایی مناسب است که نمی‌خواهند روش پرداخت اقساطی اسنپ‌پی برای همه محصولات فعال باشد.

برای مثال:

- مخفی کردن اسنپ‌پی برای دسته‌بندی **کوهنوردی و کمپینگ**
- مخفی کردن اسنپ‌پی برای یک یا چند **برند خاص**
- مخفی کردن اسنپ‌پی فقط برای چند **محصول مشخص**
- مدیریت قوانین بدون نیاز به کدنویسی

## امکانات

- انتخاب چند دسته‌بندی محصول ووکامرس
- انتخاب برند بر اساس taxonomy برند فروشگاه
- پشتیبانی از taxonomyهای رایج برند مثل `pa_brand` و `product_brand`
- انتخاب چند محصول مشخص با جستجوی محصول در ووکامرس
- امکان تغییر شناسه درگاه اسنپ‌پی
- سازگار با HPOS ووکامرس
- سبک، ساده و بدون تغییر در هسته وردپرس یا ووکامرس

## منطق عملکرد

شرط‌ها به صورت «یا» بررسی می‌شوند.

یعنی اگر محصول داخل سبد خرید فقط با یکی از این موارد همخوانی داشته باشد، درگاه اسنپ‌پی حذف می‌شود:

- دسته‌بندی انتخاب‌شده
- برند انتخاب‌شده
- محصول مشخص‌شده

مثلاً اگر دسته‌بندی «کوهنوردی و کمپینگ» انتخاب شده باشد، هر محصولی از این دسته داخل سبد خرید باشد، اسنپ‌پی در صفحه پرداخت نمایش داده نمی‌شود.

## نصب افزونه

1. فایل ZIP افزونه را دانلود کنید.
2. وارد پیشخوان وردپرس شوید.
3. از مسیر **افزونه‌ها → افزودن → بارگذاری افزونه** فایل ZIP را آپلود کنید.
4. افزونه را فعال کنید.
5. از مسیر **ووکامرس → نمایش درگاه اسنپ‌پی** تنظیمات را انجام دهید.

## تنظیم شناسه درگاه اسنپ‌پی

شناسه پیش‌فرض درگاه در افزونه `snappay` است.

اگر افزونه اسنپ‌پی شما شناسه متفاوتی دارد، از آدرس تنظیمات درگاه در ووکامرس مقدار `section` را بردارید.

مثلاً در این آدرس:

```text
wp-admin/admin.php?page=wc-settings&tab=checkout&section=wc_gateway_snapppay
```

شناسه درگاه این است:

```text
wc_gateway_snapppay
```

همین مقدار را در بخش **شناسه درگاه** افزونه وارد کنید.

## سوالات رایج

### آیا افزونه فقط برای اسنپ‌پی است؟

به صورت پیش‌فرض برای اسنپ‌پی ساخته شده، اما اگر شناسه یک درگاه دیگر را وارد کنید، می‌تواند همان درگاه را هم بر اساس دسته، برند یا محصول مخفی کند.

### آیا برای برندها باید افزونه برند خاصی نصب باشد؟

افزونه از taxonomy برند فروشگاه استفاده می‌کند. اگر فروشگاه شما از افزونه برند استفاده می‌کند، کافی است taxonomy برند را در تنظیمات انتخاب کنید و ذخیره کنید تا برندها نمایش داده شوند.

### اگر چند محصول داخل سبد باشد چه اتفاقی می‌افتد؟

اگر حتی یکی از محصولات سبد خرید با قوانین انتخاب‌شده همخوانی داشته باشد، درگاه اسنپ‌پی مخفی می‌شود.
