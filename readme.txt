Hide the SnappPay WooCommerce payment gateway for selected categories, brands, or products.

Developer: Nima Shadman - https://nimashadman.ir

== Description ==

افزونه SnappPay Conditional Gateway Hide برای فروشگاه‌های ووکامرس ساخته شده تا مدیر سایت بتواند درگاه اسنپ‌پی را برای بعضی کالاها مخفی کند.

با این افزونه می‌توانید مشخص کنید اسنپ‌پی برای دسته‌بندی‌های خاص، برندهای خاص، یا چند محصول مشخص در صفحه پرداخت نمایش داده نشود.

نمونه کاربرد:

* مخفی کردن اسنپ‌پی برای دسته‌بندی کوهنوردی و کمپینگ
* مخفی کردن اسنپ‌پی برای برندهای خاص
* مخفی کردن اسنپ‌پی برای چند محصول مشخص
* مدیریت ساده از داخل پنل ووکامرس

شرط‌ها به صورت OR کار می‌کنند. یعنی اگر یک محصول داخل سبد خرید با دسته، برند یا محصول انتخاب‌شده همخوانی داشته باشد، درگاه اسنپ‌پی مخفی می‌شود.

== Installation ==

1. فایل افزونه را دانلود کنید.
2. در پیشخوان وردپرس وارد بخش افزونه‌ها شوید.
3. از گزینه افزودن و سپس بارگذاری افزونه استفاده کنید.
4. فایل ZIP افزونه را آپلود و فعال کنید.
5. از مسیر ووکامرس > نمایش درگاه اسنپ‌پی تنظیمات را انجام دهید.

== Frequently Asked Questions ==

= شناسه درگاه اسنپ‌پی را از کجا پیدا کنم؟ =

در ووکامرس وارد تنظیمات پرداخت شوید و روی درگاه اسنپ‌پی کلیک کنید. مقدار بعد از `section=` در آدرس صفحه، شناسه درگاه است.

مثلاً اگر آدرس شامل این مقدار باشد:

`section=wc_gateway_snapppay`

شناسه درگاه شما `wc_gateway_snapppay` است.

= آیا شرط‌ها با هم ترکیب می‌شوند؟ =

بله، اما به صورت «یا». یعنی کافی است محصول با یکی از شرط‌ها همخوانی داشته باشد تا اسنپ‌پی نمایش داده نشود.

= آیا با برند ووکامرس کار می‌کند؟ =

بله، اگر برندهای فروشگاه به صورت taxonomy ثبت شده باشند، می‌توانید taxonomy برند را از تنظیمات افزونه انتخاب کنید.
